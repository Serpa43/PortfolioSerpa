# Portfolio - Lucas Serpa

Portfólio pessoal em React (Vite), com seções: Home, Sobre, Skills e Currículo.

## Pré-requisitos

- Node.js 18+ e npm

## Como rodar

```bash
# Instalar dependências
npm install

# Desenvolvimento (abre em http://localhost:5173)
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## Estrutura

- `src/components/` – componentes React (Header, Home, About, Skills, Curriculum, Footer)
- `src/hooks/` – hook `useReveal` para animação ao scroll
- `public/img/` – imagens estáticas
- `index.html` – entrada do Vite
- `vite.config.js` – configuração do Vite

## Stack

- React 18
- Vite 6
- react-icons
